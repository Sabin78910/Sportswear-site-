# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-02

### Added
- Scroll-driven background film at full opacity, with H.264 and VP9 all-intra encodes.
- Lap timer showing the current film time and scroll progress.
- Hero, statement, featured product, Lap Collection, Pit Lane Capsule and footer sections.
- Product catalogue with category filters and per-product size selection.
- Bag drawer with quantity controls, a free-shipping meter and totals, saved to `localStorage`.
- Newsletter form with validation.
- GitHub Pages deployment workflow.
